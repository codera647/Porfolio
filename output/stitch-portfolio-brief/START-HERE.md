# Give this package to Google Stitch

1. Extract the package. Attach the **four PNG files in `upload-images`** to Stitch:
   - `01-signature-intro.png`
   - `02-split-hero-reference.png`
   - `03-name-and-glow-reference.png`
   - `04-brand-and-signature.png`
2. Paste all of `GOOGLE-STITCH-PROMPT.txt` into Stitch. The Markdown file has identical content with easier formatting for review. Paste the text directly if document attachment is unavailable.
3. Optionally attach `signature/abdul-moiz-signature-light.png` for the clean transparent signature. Keep SVG files for later implementation; they are not required uploads.
4. Ask Stitch to produce the desktop hero and its rest/hover states first, then extend the same design to the other frames listed in the brief. Keep the full brief as the source of truth throughout.

**No video upload is needed.** The images show selected visual states; the prompt explains their sequence, timing, pointer response, and easing in words. The PNG board captions are annotations, not elements to copy into your website. If attachments are limited, prioritize boards 04 and 03; the prompt is also self-contained without images.
