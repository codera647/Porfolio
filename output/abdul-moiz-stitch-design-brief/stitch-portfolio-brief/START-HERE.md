# Give this package to Google Stitch

1. Upload your original `v1.mp4`, `v2.mp4`, and `v3.mp4` videos. If a video cannot be attached, use the matching stills from `references` instead.
2. Attach `signature/abdul-moiz-signature-light.png` as the visual signature reference. Keep the SVG and MP4 files available for motion/design handoff.
3. Paste all of `GOOGLE-STITCH-PROMPT.txt` into Stitch. The Markdown file has identical content with easier formatting for review.
4. Ask Stitch to produce the desktop hero and its rest/hover states first, then extend the same design to the other frames listed in the brief. Keep the full brief as the source of truth throughout.

## What is included

- A detailed design prompt covering the reference roles, theme, exact name treatment, page composition, loading sequence, pointer effects, responsive layouts, lower sections, accessibility, and design deliverables.
- Original Abdul Moiz signature artwork: editable vector paths, true transparent PNG previews, a self-contained animated SVG, a timing manifest, and a short animation preview.
- Reference stills extracted from the videos and the existing color palette.

This package implements signature artwork only. It contains no website implementation. The avatar direction has been omitted from this brief and package.

## Content to personalize later

Your name and font are confirmed. Your role, biography, project content, email address, and profile URLs are placeholders. Replace them with your real information before publishing a design or website.

## Motion scope

Stitch supports creating designs and connecting screens into interactive prototypes. Exact pointer-following gradients and continuous font interpolation may require a later implementation. The prompt therefore requests both prototype states and specific motion annotations, without depending on unverified 3D or shader import capabilities.

Official product context: [Google's introduction to the Stitch design canvas and prototypes](https://blog.google/innovation-and-ai/models-and-research/google-labs/stitch-ai-ui-design/), [Google's Stitch workflow update](https://blog.google/innovation-and-ai/models-and-research/google-labs/stitch-updates/).
